## 修复：爪子"虚空抓取"

问题：判定点在绳索末端，而视觉爪尖在其下方约 22px，加上判定半径过大、抓取瞬间物品被瞬移到爪子正前方，导致"隔空抓物"。

修复内容：
- 在 config.ts 增加 `CLAW_GRAB_OFFSET = 14`（爪子怀抱中心）与 `CLAW_TIP_OFFSET = 22`（爪尖）。
- Engine.ts：
  - `hitTest()` 判定点前移到 `length + CLAW_GRAB_OFFSET`，判定半径收紧为 `radius * 0.85 + 6`。
  - `maxReach()` 按爪尖计算边界，避免爪尖穿帮。
  - 抓取后不再瞬移，而是每帧用 lerp 平滑归位到 `length + CLAW_GRAB_OFFSET + radius * 0.3`。
  - 炸药引爆、TNT 爆炸、飘字/粒子位置改用物品自身坐标，更准确。
- draw.ts：`drawHook` 增加 `closed` 参数，抓到物品时两爪收拢；调整 `drawBag` 视觉中心偏移。
- 用无头 Chrome + 定时器驱动引擎做几何验证：爪子命中 rock(r=30) 时，爪尖插入物品内部约 6.9px，符合预期。
- （续）无头 Chrome 端到端复核（dev 服务器 5188）：瞄准真实 goldSmall 发射，angErr=0.000（爪子方向与目标完全一致、无镜像）、dGrab=16.6 < 判定半径 17、money+50，确认 Canvas 版「方向相反/虚空抓取」问题已彻底解决。Phaser 版采用同一方向约定（dir=(sin,cos)，绘制与判定共用 tip），同样无虚空抓取。

## 升级：Phaser 版从 3.80 → 4.0.0

用户要求 Phaser 使用 4.0。改动与 Phaser 4 破坏性差异：

- `package.json`：phaser `^3.80.0` → `^4.0.0`，重新 `npm install` 落地。
- Phaser 4 ESM 为**具名导出、无 default**：`import Phaser from 'phaser'` 在 rolldown/vite build 报 `MISSING_EXPORT "default"`。改为 `import * as Phaser from 'phaser'`（两处：src/phaser/main.ts、GameScene.ts）。
- `Phaser.Geom.Point` 在 Phaser 4 已被移除，`Graphics.fillPoints` 现要求 `Phaser.Math.Vector2[]`：drawDiamond 中的 `new Phaser.Geom.Point(...)` 改为 `new Phaser.Math.Vector2(...)`。
- 开始覆盖层文案「Phaser 3 引擎版」→「Phaser 4 引擎版」。

验证：
- `npm run build` 通过（vue-tsc + vite build，phaser chunk 1.36MB 仅体积警告）。
- 无头 Chrome 运行时测试：Phaser.VERSION=4.0.0，场景启动正常、物品生成 10 个；瞄准 gold(r=25) 发射，爪尖距物品中心 29.7px < 判定半径 30，`insideClaw=true`，无虚空抓取、方向正确（无镜像）；`AUTO/Scale.FIT/Scale.CENTER_BOTH/Math.Vector2/Geom/Tweens` 命名空间常量均存在；无 JS 报错。
- 结论：Phaser 版黄金矿工已运行在 Phaser 4.0.0。
