# 接睫乐

近视防控主题的竖屏 H5 接取游戏，使用 Vue 3、TypeScript、Vite 和 Phaser 4 构建。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

构建产物位于 `dist/`，Vite 已设置相对资源路径，可直接部署到静态站点的子目录。

## 玩法

- 左右滑动或使用键盘方向键控制角色。
- 接住日间户外、远眺、充足睡眠等好习惯获得分数。
- 避开长时间看屏、躺着阅读、昏暗用眼等坏习惯。
- 初始 5 点生命，接错物品会失去生命。
- 结束后生成仅基于本轮游戏表现的趣味指数报告，不作为医学筛查或诊断。

科普文案参考国家卫生健康委《防控儿童青少年近视核心知识十条》及相关公开材料。
