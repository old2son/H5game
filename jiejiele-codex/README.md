# 接睫乐

近视防控主题的竖屏 H5 接取游戏，使用 Vue 3、TypeScript、Vite 和 Phaser 4 构建。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

构建产物位于 `dist/`，Vite 已设置相对资源路径，可直接部署到静态站点的子目录。

## 玩法

- 左右滑动或使用键盘方向键控制角色。
- 接住日间户外、远眺、充足睡眠等好习惯获得分数。
- 避开长时间看屏、躺着阅读、昏暗用眼等坏习惯。
- 初始 5 点生命，接错物品会失去生命。
- 结束后生成仅基于本轮游戏表现的趣味指数报告，不作为医学筛查或诊断。

科普文案参考国家卫生健康委《防控儿童青少年近视核心知识十条》及相关公开材料。

## 角色行走帧

角色只有一张正面站立立绘 `public/assets/orange-eye-mascot-original.png`。
行走 / 待机帧由脚本从这张图派生，不依赖第二套美术：

```bash
python tools/generate-walk-frames.py
```

- 输出 `public/assets/orange-eye-mascot-walk.png`：12 帧横排 spritesheet，每帧 320×320，
  帧 0-7 是向右走的循环，帧 8-11 是待机呼吸；角色只占帧宽 86%，留白给旋转和弹跳。
- 动作由挤压拉伸 + 前倾 + 上下弹跳组合而成（角色没有腿），锚点是轮廓底边中点。
- 游戏里只加载这一张图：向右走直接播帧，向左走用 `sprite.setFlipX(true)` 水平翻转，
  所以不需要单独一套朝左的资源。见 `CatchGameScene.updatePlayerPose()`。
- 行走帧按**位移**推进（每走 52px 一帧），不是按时间空转：挪一点点只推进一点点，
  松手后还会惯性多迈 140ms 再回待机，所以小幅移动不会出现反复重播的抽搐感。
  全速 750px/s 时约 14 帧/秒，速度越慢步子越慢。
- 停下来时角色会绕脚底抖几下（约 0.7s 的指数衰减挤压，幅度随停下前的速度变化），
  不会一停就僵住。参数是 `MASCOT_SETTLE_*`。
- 想单独看帧序列可以加 `--preview`，会在 `tools/preview/` 生成对照图和 GIF（默认不生成）。

换了新的站立立绘后重跑脚本即可，帧数、幅度都在脚本顶部的 `WALK_FRAMES` / `IDLE_FRAMES` 里调。
