## 排查「装了 phaser4 却打印 v3.90.0」
- 现象：浏览器 console 打印 `Phaser v3.90.0`，但 package.json/包内 VERSION 均为 4.0.0。
- 根因：dev server 是升级前的旧实例，node_modules 换了 Vite 不会自动换血；且本项目同时跑了 3 个 vite dev server 进程（至少一个是 3.90.0 残留）。`vite build` 会重解析 node_modules 所以 dist 是 4.0.0、dev 却是 3.90.0。
- 验证：`node -e "console.log(require.resolve('phaser'))"` → dist/phaser.js；grep 其 `VERSION: '4.0.0'`；`Get-CimInstance Win32_Process` 找 vite 进程（commandline 含 shenmiaotaopao）定位 PID。
- 修复：停掉 3 个旧 vite 进程（保留 secha 项目的 20420）→ `rm -rf node_modules/.vite` → 重启 `npm run dev`（5175），重新预打包缓存已确认只有 4.0.0。浏览器需硬刷新。
- 经验：换依赖大版本后务必重启 dev server，或 `rm -rf node_modules/.vite` 后再 `npm run dev` / `vite --force`。

## 竖屏文字被裁切（头部切一点）
- 现象：菜单「点击屏幕/右侧按钮=跳跃」、GameScene「最远」贴边文字头部被裁掉一点。
- 根因：`main.js` applyOrientation 竖屏缩放用 `cover = Math.max(w/dH, h/dW)`（放大铺满），一旦画布宽高比与屏幕有微小偏差（手机浏览器地址栏导致 innerHeight≠实际视口、或 GAME_WIDTH 被 1280 上限裁剪），就裁掉边缘，而贴边 UI 正好中招。
- 修复：改成 `cover = Math.min(w/dH, h/dW)`（contain 等比）。手机竖屏画布比例本就等于屏幕旋转后比例，故通常≈填满且不裁不空；仅在比例异常时留极窄边条（body 底色已是天空蓝 #87ceeb 可融合）。`transformPointer` 反旋转仍用同一 orient.cover，输入映射不受影响。
- 经验：竖屏旋转宁可「缩小留边」也不要「放大裁边」，否则贴边文字必被切。

## 结算文字顶部被裁（gameOver 的「游戏结束/本局距离」）
- 现象：游戏结束后「游戏结束」「本局距离」顶部被切一点，但下方「金币/重新开始」正常。
- 根因（与上次不同，这次是**显示层居中冲突**，不是相机）：`main.js` 用 `autoCenter: CENTER_BOTH` + CSS `transform: rotate(90deg) scale()`。Phaser 的 CENTER_BOTH 会给 canvas 加 `margin` 来居中，和我们自己的旋转缩放 transform **叠加**，使画布实际中心偏离屏幕中心、整体被推上去 → 顶部文字推出可视区。
- 已排除相机：相机主视口取 `sys.scale.width` = `gameSize.width`（config 原始宽高 = GAME_WIDTH*DPR），`centerOn` 后 scroll=0，可见区正是 (0,0)-(GAME_WIDTH,GAME_HEIGHT)，不会切顶部。
- 修复：① `config.scale.autoCenter` 改 `Phaser.Scale.NO_CENTER`；② `applyOrientation` 改为 `position:fixed; left/top:50%; transform:translate(-50%,-50%) rotate(90deg) scale(visScale)` 自行精确居中（旋转/缩放绕屏幕正中）；竖屏 `visScale = min(w/dH,h/dW)*0.995` 留 0.5% 安全边防边缘过盈；横屏 `translate(-50%,-50%)` 仅居中。`transformPointer` 反旋转仍用真实 `cover` 保触摸精准。③ `GameScene.gameOver` 文字整体上移安全边距（0.28→0.32、0.44→0.46、0.56→0.58、0.74→0.76）作保险。
- 构建通过。
- 经验：Phaser 的 `autoCenter` 与「自己给 canvas 加 transform 旋转缩放」会冲突，凡要 CSS 旋转画布必须关掉 Phaser 自动居中、自行用 fixed+translate 居中。
