## 修复人物图片三问题（16:51）
- 问题：① 图片无背景透明（实为 colortype=2 RGB 不透明，被白底方块包裹）；② 4 帧独立生成服装/细节不一致，人物无故变化；③ 跑步动作需≥2张。
- 根因：ImageGen 的 `background: transparent` 参数被后端忽略，输出均为 RGB 无 alpha 通道。
- 修复：
  - 重新生成：先生成 1 张基准角色（蓝衣红头带男孩，绿幕背景），再 image-to-image 基于该基准生成 run0(左腿前)/run1(右腿前)/jump/slide，保证角色完全一致。
  - 后处理去背：用 Pillow（managed venv `envs/default`）采样四角背景色，将接近背景色像素设为透明（含边缘平滑），输出 RGBA 真正透明 PNG。
  - 统一尺寸：用 bbox 裁剪到角色并 resize（run/jump 256x320，slide 320x180，脚底对齐底边），便于精确设置碰撞体。
  - 代码：`BootScene.js` 跑步动画改为 2 帧（run0/run1）；`Player.js` 按新纹理尺寸重设 displaySize 与 body 碰撞体（stand/jump 156x270@(50,50)，slide 256x85@(32,95)）。
  - 清理：删除临时源图（Cartoon_*/Identical_*）、旧 run2/run3 与辅助脚本（check_alpha.py/remove_bg.py/process.py）。
- 验证：`dist/characters/` 4 张图均为 RGBA 且含透明像素；`npm run build` 通过。
