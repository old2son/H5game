## 色系规则调整（src/App.vue）
- 用户要求：同一局只能用一个色系，每一关不同饱和度，重开一局才换色。
- 实现：新增 `gameHue`（本局固定色相，在 `startGame()` 用 `rand(0,360)` 选一次）与 `lastSat`（上一关饱和度）。
  - `newLevel()`：`state.baseH = gameHue`（不再每关随机色相）；饱和度 `state.baseS` 每关在 [55,82] 内随机且与上一关差距 >=8，保证每关不同；`baseL` 仍每关随机 [40,62]（目标块靠亮度差区分）。
  - `startGame()`：开局重选 `gameHue = rand(0,360)` 并 `lastSat = -1`，实现「重开一局才换色」。
- 验证：`vue-tsc -b` exit 0；`npm run build`（非沙箱）exit 0，dist JS 74.43KB/gzip 30.07。dev 5173 仍在运行，HMR 热更。
- 说明：此改动系用户主动提出的明确需求，不属「未经同意新增功能」。其余功能（科普卡/灵敏度/分享/音效）未动。
