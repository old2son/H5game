# 2026-08-25

- 在 secha 项目从零搭建了 Vite + Vue3 + TS 的「色差挑战」小游戏（Canvas 渲染）：在 N×N 同色方块中找出颜色不同的那一个，点中升级（网格变大/色差变小/时间变短），点错或超时则结束。入口：index.html / vite.config.ts / tsconfig*.json / src/main.ts / src/App.vue / src/style.css。
- dev 命令：`npm run dev`（vite，端口 5173，已 host 开启）。游戏逻辑在 src/App.vue，使用 Canvas 绘制 + pointerdown 命中检测 + requestAnimationFrame 倒计时，适配 HiDPI 与窗口缩放，最佳分存 localStorage。
- ⚠️ 重要：本沙箱中 `npm install` 在沙箱隔离下会卡住（网络出口被拦，16 分钟 0 包）；需以非沙箱方式运行（验证：加 `--no-audit --no-fund --loglevel=http` 后约 40s 装好 232 包）。后续在此项目装依赖请走非沙箱通道。
