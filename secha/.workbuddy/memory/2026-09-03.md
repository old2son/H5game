## 需求：通过第 10 关后恭喜用户全部通关（用户明确要求）

### 改动（仅 src/App.vue）
1. 新增常量 `const MAX_LEVEL = 10`（总关卡数）与状态 `const cleared = ref(false)`（本局是否全部通关）。
2. `handlePoint()` 答对分支：
   - 原逻辑无条件 `level += 1; newLevel()`；
   - 改为：若 `level.value >= MAX_LEVEL` → `cleared.value = true; gameOver()`（不再进下一关）；
   - 否则照旧 `level += 1; newLevel(); sfxLevel()`。
3. `gameOver()`：
   - 音效/震动按通关分支：`cleared ? sfxWin() + buzz([30,50,30,50,120]) : sfxOver() + buzz([60,40,60,40,60])`；
   - 灵敏度峰值 `peak = cleared.value ? MAX_LEVEL : level.value - 1`（通关即 10 关 → 灵敏度 100 分）。
   - 新增 `sfxWin()`：523/659/784/1047 Hz 上行琶音，triangle，间隔 110ms。
4. `startGame()` 重置 `cleared.value = false`。
5. 模板：
   - 标题 `{{ cleared ? '🎉 全部通关' : '游戏结束' }}`；
   - 新增 `.win-text` 恭喜文案（v-if="cleared"）；
   - 「到达关卡」在通关时改为「通关进度」+ `MAX_LEVEL / MAX_LEVEL`。
6. 样式：新增 `.win-text`（#9be7c4，居中），PC 媒体查询下字号 15px。
