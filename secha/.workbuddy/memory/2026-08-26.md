# 2026-08-26

- 修复 TS 报错 TS6310「引用的项目 tsconfig.node.json 可能不会禁用发出」。根 tsconfig.json 通过 `references` 引用 tsconfig.node.json，而该文件设了 `noEmit: true`；在 build 模式（vue-tsc -b / 编辑器 project references）下 composite 被引用项目禁止 noEmit。
- 修复方式：tsconfig.node.json 移除 `noEmit`，改为 `composite: true` + `tsBuildInfoFile` 与 `outDir` 指向 `node_modules/.tmp`（配合 `emitDeclarationOnly: true`），产物不外泄到仓库。验证 `vue-tsc -b` 与 `vue-tsc` 均 exit 0。

- 修复色差游戏「点错方块→结束」时同一次手势穿透触发「再来一局」按钮的 bug：点错 → `gameOver()` 立即渲染覆盖在 canvas 上的 overlay 按钮，pointerup 合成 click 落在新按钮上导致 `startGame()` 被瞬间再次调用，结果弹窗一闪即重新开始。修复：新增 `replayReady` 标志，`gameOver()` 时置 false 并 350ms 后置 true；「再来一局」按钮改走 `onReplay()`，未就绪时直接忽略点击。顺手删掉两处 `console.log(state.cell)` 调试输出。
- 注：`vite.config.ts` 设了 `base: '/secha/'`，本地预览正确地址为 `http://localhost:5173/secha/`（不是根路径 `/`）。
